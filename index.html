Config preview

A quick look at how Gate represents routes and policies.

gate.yaml

services:
  - name: lobby
    upstreams:
      - address: lobby-service:25565
    policies:
      rateLimit:
        rpm: 600
      allowList:
        - 198.51.100.0/24
routes:
  - host: play.example.com
    service: lobby
    tls: true

deployment notes

- Validate upstream health before rollout
- Use canary releases for traffic shifting
- Monitor latency after policy changes
