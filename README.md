# AmpConfigGate

AMP landing page for [gate.minekube.com](https://gate.minekube.com/).

## Quick start

- Open `index.html` in a browser, or
- Run `npm start` and visit the local URL printed by the server.

## Notes

- The page is AMP HTML and requires the AMP runtime scripts included in `index.html`.
- Update the `action-xhr` endpoint in the contact form when a production endpoint is available.
